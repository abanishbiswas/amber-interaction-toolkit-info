# AMBER Protein–Ligand Interaction Analysis Toolkit

A research-oriented toolkit for analysing protein–ligand interactions from AMBER molecular dynamics trajectories.

The toolkit is currently under active development and validation. The source code is being maintained in a private repository during this stage.

## Current capabilities

- Hydrogen-bond analysis
- Hydrophobic interaction analysis
- Parallel π–π interaction analysis
- T-shaped π–π interaction analysis
- Ionic / salt-bridge interaction analysis
- Cation–π interaction analysis
- Residue-wise interaction occupancy
- Event-level interaction tables
- Representative-frame selection
- Publication-ready interaction plots
- Residue numbering restoration for analysis outputs

## Scientific objective

The project is intended to provide a reproducible and transparent workflow for analysing protein–ligand interactions across molecular dynamics trajectories.

Interaction events are stored at the frame level so that selected interactions and representative structures can be independently inspected using structural-analysis and visualization software.

## Source code access

The source code is currently private while the toolkit is undergoing development, validation, and preparation for publication.

Researchers interested in testing or using the toolkit for academic research may request access by opening an **Issue** in this repository.

Please include the following information in the request:

- Name
- Institution / affiliation
- Research purpose
- GitHub username

Suggested issue title:

`Request for source code access`

Access may be provided on a case-by-case basis during the development and validation stage.
